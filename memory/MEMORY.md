# Project memory

This folder is the company memory for this open source Kortix starter. It is plain Markdown, versioned in the repo. The agent reads it at the start of a session and appends what it learns.

## Index

- `MEMORY.md`: this index.
- Add one file per topic as the project learns it, for example `memory/customers.md` or `memory/release-process.md`.

## How to use it

Keep entries short and factual. Name the source. Update an entry in place when a fact changes, so the folder stays the current truth rather than a log of drafts.
